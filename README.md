# MTT-Trainingsplan 

Digitaler Trainingsbegleiter – kontinuierlich, ohne festes Enddatum.

## Features
- **Unbegrenzte Laufzeit** ab 20.05.2026, Mo / Mi / Fr
- Wochennavigation (vor/zurück blättern)
- Alle 15 Übungen mit Gewicht, Schmerz-Tracking & Hinweisen
- **Befinden-Tracking** per Emoji
- **Aktivitäten-Log**: Radfahren (km + Min), Walken (km + Min), Schwimmen (m + Min), Sonstiges
- **Motivierender Spruch** zu Beginn jeder Einheit
- **Auswertung** in drei Tabs:
  - Gesamt: Gewichtsprogression & Schmerzhistorie
  - 4-Wochen-Check: automatische Empfehlungen zur Trainingsanpassung
  - Aktivitäten: Gesamtübersicht aller Ausdauerbewegungen
- **Automatisches Speichern** via localStorage (Daten bleiben beim Neuöffnen erhalten)

## Deployment (GitHub Pages)

1. Neues Repository erstellen (z. B. `mtt-trainingsplan`) → **Public**
2. `index.html` + `README.md` hochladen
3. Settings → Pages → Branch: `main` / `/(root)` → Save
4. Nach ~1 Min erreichbar unter:
   `https://[dein-username].github.io/mtt-trainingsplan/`

## Datenschutz
Alle Daten bleiben **lokal im Browser** (localStorage). Kein Server, kein Login, keine Cloud.
Bei Gerätewechsel werden Daten nicht automatisch übertragen.
